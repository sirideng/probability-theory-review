# Probability Atlas · 概率论与机器学习学习地图

面向北京师范大学珠海校区应用统计学本科生的长期学习网站。目前包含彼此并列、独立记录进度的两条路线：以期末高分复习为目标的概率论知识本，以及跟随吴恩达 Machine Learning Specialization 学习进度整理的机器学习路线。

项目将公式、例题、解题方法、交互图像和可运行的 Python 示例组织在统一的响应式界面中，既适合系统学习，也适合考前快速检索。

## 架构思路

项目采用四层结构：

1. **内容数据层**：概率论内容按 JSON 分章管理；机器学习课程使用类型化 TypeScript 数据，避免学习内容散落在页面组件中。
2. **页面层**：概率论与机器学习拥有并列入口和独立学习地图，知识详情、分布图像、公式速查、考前速览和连接科学分别使用独立路由。
3. **通用组件层**：侧栏、长页目录、阅读进度、章节锚点、公式、代码高亮和交互实验台可以复用。
4. **计算与可视化层**：使用 React + SVG 原生绘图；概率、分位点和模型训练结果来自统一数学函数，而不是图表像素近似。

```text
src/
├─ components/
│  ├─ distributions/   # 分布曲线与小型预览图
│  ├─ machine-learning/ # 机器学习交互实验台
│  ├─ navigation/      # 长页目录、锚点与阅读进度
│  ├─ code/            # Python 语法高亮
│  ├─ home/            # 首页知识地图
│  ├─ layout/          # 全局导航与页面框架
│  └─ ui/              # 通用界面组件
├─ data/
│  ├─ knowledge/       # 分章知识点与复习内容
│  ├─ distributions.json
│  ├─ formulas.json
│  └─ machine-learning-course*.ts
├─ pages/              # 路由页面
├─ utils/              # 数学计算、深链接与进度存储
└─ types/              # 内容模型 TypeScript 类型
```

## 已完成内容

- iOS 液态玻璃风格的响应式整体框架
- 概率论与机器学习双路线入口，学习进度分别保存
- 第一至第五章 28 个完整知识页面
- 每页统一包含核心理解、数学定义、直观解释、示意图、核心性质、常见题型、易错点和知识关联
- KaTeX 规范 LaTeX 公式渲染
- 0-1、二项、泊松、几何、均匀、指数、正态 7 个基础分布交互页
- 卡方、t、F 分布的数理统计衔接预览与交互页
- PDF/PMF、CDF、区间概率与分位点反查实验台
- 公式速查、考前速览、讲义入口和“连接科学”专题
- 长内容页的悬浮目录、阅读进度、章节锚点和深链接
- 机器学习视频 1—36 的 14 个学习模块：线性回归、梯度下降、多特征、特征缩放、多项式回归、逻辑回归、过拟合与正则化
- 机器学习交互实验、手算例题以及带语法高亮和行号的 Python 示例

内容组织参考北京师范大学珠海校区应用统计专业概率论课程定位与李勇老师《概率论》教材所强调的知识构建、概率建模和应用主线。网站正文为复习型重述，不复制教材原文。

机器学习路线参考吴恩达 2022 版 Machine Learning Specialization 的课程顺序，并结合概率论基础重新组织为原创中文复习内容；当前整理至第 36 集“正则化逻辑回归”。

## 本地运行

日常复习可以直接双击项目根目录中的 `概率论学习系统.html`。这是打包后的单文件离线版，不需要启动服务器，也不需要保持命令窗口打开。

请不要直接双击源码入口 `index.html`。修改项目时仍可双击 `启动网站.cmd` 进入开发模式；命令窗口关闭后，开发服务器会停止。

也可以使用命令行：

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

## 扩展方式

- 新增知识点：在 `src/data/knowledge/chapter-*.json` 对应章节文件中增加同结构对象，再在 `curriculum.json` 配置学习地图节点。
- 新增分布：先在 `distributions.json` 建立元数据，再为需要交互的分布增加独立 SVG 图表组件。
- 新增章节：扩展首页地图节点与知识 JSON，不需要改动整体布局。
- 接入数理统计：沿用知识详情模板，并在第六章增加抽样分布、估计、检验与回归的连接关系。
- 更新机器学习：在 `machine-learning-course*.ts` 中按学习进度增加模块，并复用课程页模板和实验台组件。
