# Probability Atlas · 概率论学习地图

面向北京师范大学珠海校区应用统计学本科生的概率论长期复习网站。首版重点不是堆积内容，而是验证一套可以稳定扩展的知识结构、页面模板与交互可视化框架。

## 架构思路

项目采用四层结构：

1. **内容数据层**：`src/data/*.json` 管理知识点、分布与公式，避免知识内容散落在页面代码中。
2. **页面层**：学习地图、知识详情、分布图像库、公式速查和数据科学连接分别拥有独立路由。
3. **通用组件层**：侧栏、页面标题、知识地图节点、分布图表等可独立复用。
4. **可视化层**：首版使用 React + SVG 原生绘制，不依赖大型图表库，便于精准控制数学坐标和动画。

```text
src/
├─ components/
│  ├─ distributions/   # 分布曲线与小型预览图
│  ├─ home/            # 首页知识地图
│  ├─ layout/          # 全局导航与页面框架
│  └─ ui/              # 通用界面组件
├─ data/
│  ├─ knowledge.json   # 知识点内容
│  ├─ distributions.json
│  └─ formulas.json
├─ pages/              # 路由页面
└─ types/              # 内容模型 TypeScript 类型
```

## 本地运行

日常复习可以直接双击项目根目录中的 `概率论学习系统.html`。这是打包后的单文件离线版，不需要启动服务器，也不需要保持命令窗口打开。

请不要直接双击源码入口 `index.html`。修改项目时仍可双击 `启动网站.cmd` 进入开发模式；命令窗口关闭后，开发服务器会停止。

也可以使用命令行：

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

## 扩展方式

- 新增知识点：在 `src/data/knowledge/chapter-*.json` 对应章节文件中增加同结构对象，再在 `curriculum.json` 配置学习地图节点。
- 新增分布：先在 `distributions.json` 建立元数据，再为需要交互的分布增加独立 SVG 图表组件。
- 新增章节：扩展首页地图节点与知识 JSON，不需要改动整体布局。
- 接入数理统计：沿用知识详情模板，并在第六章增加抽样分布、估计、检验与回归的连接关系。
