# 机器学习课程术语与符号规范

本规范适用于机器学习学习地图、14 个课程模块、交互实验台、公式说明、Python 代码解释、常见误区与本节回顾。新增内容应先与本表对照。

## 核心术语

- **损失函数（loss function）**：衡量单个样本预测与真实结果之间的差异，记为 `L`。
- **代价函数（cost function）**：汇总整个训练集上的损失，记为 `J(w,b)` 或 `J(\mathbf w,b)`。
- **目标函数（objective function）**：优化算法最终优化的完整函数。加入正则项后，数据拟合项与正则项共同组成目标函数。
- **特征（feature）**：模型的输入变量。回归输出称为目标值或目标变量；分类输出称为类别标签。
- **训练数据、训练算法、参数、模型、预测**：数据提供信息；算法优化参数；参数确定预测函数；模型是使用已确定参数进行预测的函数；预测是把未见输入送入模型得到输出。
- **梯度与负梯度**：梯度指向函数局部增长最快方向；梯度下降减去梯度，沿负梯度方向更新参数。
- **多元线性回归（Multiple Linear Regression）**：正式名称；“多特征线性回归”只作直观解释，不使用“多重线性回归”。
- **Sigmoid函数（逻辑函数）**：首次出现使用全称。`z` 是线性得分，`\hat p` 是正类概率估计，`\hat y` 是应用阈值后的预测类别。
- **Z-score标准化、L2正则化、NumPy、Python、Jupyter Notebook**：统一使用这些写法。

## 统一数学符号

- 标量：`x,w,b,y`；向量：`\mathbf x,\mathbf w,\mathbf y`；矩阵：`X`。
- 第 `i` 个样本：`\mathbf x^{(i)}`；第 `j` 个特征：`x_j`；第 `i` 个样本的第 `j` 个特征：`x_j^{(i)}`。
- 训练样本数：`m`；特征数：`n`；预测值：`\hat y`；正类概率估计：`\hat p`。
- 单样本损失：`L`；训练集代价或完整目标：`J`；学习率：`\alpha`；正则化强度：`\lambda`；停止阈值：`\varepsilon`。
- 同步更新使用 `w_{\text{new}}`、`b_{\text{new}}` 或向量形式 `\mathbf w_{\text{new}}`，不混用其他数学记法。代码变量可保持 Python 风格，但解释必须指出其数学含义。

## 写作边界

- `J=\frac{1}{2m}\sum(\hat y-y)^2` 称为平方误差代价函数，解释为“平方误差之和除以 `2m`”或“均方误差的一半”，不直接称为 MSE。
- 概率论中的随机变量方差描述随机变量的波动；机器学习中的模型方差描述模型对训练样本变化的敏感程度。二者相关但定义不同。
- 对“必然、一定、必须、只能、完全、总是、证明、自动、所有”等绝对化词语逐句检查，并明确成立条件。
- 未见数据指训练集之外的数据。训练集拟合良好不等于泛化表现良好。
